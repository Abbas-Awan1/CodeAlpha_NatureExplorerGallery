# 🌿 Nature Explorer Gallery

A Modern Responsive Image Gallery Built with HTML, CSS & JavaScript.

📖 Project Description

Nature Explorer Gallery is a modern frontend web application created as part of my Frontend Development Internship. The project showcases beautiful nature photography through an interactive and responsive gallery.

Users can browse images by category, open images in a fullscreen lightbox, navigate between images, and upload their own nature photos. Uploaded images are stored using the browser's Local Storage, allowing them to remain available after refreshing the page.

The main goal of this project was to improve my frontend development skills by building a visually appealing and interactive web application using only HTML, CSS, and JavaScript.

- 🌄 Fullscreen Hero Landing Page
